# CityScope Volpe AR — web app

The built web app of CityScope Volpe AR, published with GitHub Pages. It is generated: do not
edit it here. Open the page in Chrome or Edge; on an ARCore Android phone it also runs in AR.

## Sources and credits

- Population: Kendall Square synthetic population, tier3.1 (Marcel Bartumeu Raméntol),
  experimental (not adopted), published with the author's permission.
- Site grid and development programs: modules of the volpe-population-vis reference app,
  published with its author's permission.
- Aerial imagery: MassGIS 2023 orthoimagery; USDA NAIP, July 2023.
- Trees: City of Cambridge GIS tree inventory, Public Domain Dedication and License (PDDL) v1.0.
- Streets, paths, piers, bridges and street lamps: © OpenStreetMap contributors, ODbL.
- Transit: MBTA GTFS feed.
- Table scan, people and vehicle figures: the project's own files (figures and vehicles baked
  from licensed models; the models themselves are not published).
